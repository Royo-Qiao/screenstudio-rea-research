# Third-party scope

- **Screen Studio** is a third-party commercial product. Its application,
  extracted source, icons, media and licensing material are not distributed here.
  The product name identifies the research target and does not imply affiliation
  or endorsement. Obtain the application from [screen.studio](https://screen.studio/).
- **REA** is the separately maintained analysis project at
  [morluto/rea](https://github.com/morluto/rea). No REA code is vendored here.
- **Ghidra** is an optional external analysis provider maintained at
  [NationalSecurityAgency/ghidra](https://github.com/NationalSecurityAgency/ghidra).
  No Ghidra code is vendored here.
- **FFmpeg/ffprobe** are user-installed external executables. This repository
  invokes them for metadata inspection and complete decoding; it bundles neither
  executable. See [FFmpeg](https://ffmpeg.org/) for its own licensing and builds.
- The MIT license in this repository covers only its original code and text.
  It does not grant rights in any inspected application or recording.
