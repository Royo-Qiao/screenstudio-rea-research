# Security and private data

These scripts parse local files and optionally invoke system `codesign`, `ffprobe`
and `ffmpeg`. They never launch the inspected app. Use trusted, current media tools
when handling untrusted files. Python dependencies are standard-library only.

For a repository tooling vulnerability, use GitHub private vulnerability reporting
when available. For vendor-product vulnerabilities, contact the vendor. Public
reports should use synthetic examples without recorded content or license data.
